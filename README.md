# happy-birthday-vladochek

Одностраничный праздничный сайт-поздравление: 15 экранов, которые листаются по кнопке,
с шутками, анимациями и финальным раскрытием, что подарок ждёт в пункте выдачи 24 августа.

Чистые HTML/CSS/JS в одном файле — без сборщиков, npm и фреймворков.
Единственная внешняя зависимость — шрифты Google Fonts (если интернета нет, подставятся системные).

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | весь сайт: разметка, стили и скрипт |
| `.nojekyll` | отключает обработку Jekyll на GitHub Pages |

## Как включить GitHub Pages

1. Запушить содержимое в репозиторий на GitHub (ветка `main`, файлы в корне).
2. Открыть **Settings → Pages**.
3. **Source** → `Deploy from a branch`.
4. **Branch** → `main`, папка → `/ (root)` → **Save**.
5. Через 1–2 минуты сайт будет по адресу `https://<логин>.github.io/<репозиторий>/`.

Локально достаточно открыть `index.html` двойным кликом — сервер не нужен.

## Где в коде менять тексты

Всё, что можно захотеть поправить, лежит **в начале тега `<script>`**, лезть в разметку не нужно.

| Что менять | Где |
|---|---|
| Дата рождения, дата подарка, номер заказа, стартовый счётчик цветов, число свечей | объект `CONFIG` |
| Все заголовки, подписи и тексты кнопок всех 15 экранов | объект `T` (ключи названы по номеру экрана: `s1_…`, `s2_…` и т. д.) |
| Комплименты (экран 7) | массив `COMPLIMENTS` |
| Вопросы капчи, правильные ответы, отклики и подсказки (экран 2) | массив `QUESTIONS` |
| Проценты и подписи фейковой загрузки (экран 3) | массив `LOADING_STEPS` |
| Эмодзи цветов (экран 4) | массив `FLOWER_EMOJI` |
| Строки диагностики (экран 10) | `T.s10_lines` и `T.s10_crit` |
| Шаги трекинга посылки (экран 11) | `T.s11_steps` |
| Реплики жабки (экран 12) | `T.s12_buttons` |
| Поля и печать сертификата (экран 14) | `T.s14_rows`, `T.s14_seal` |

В CSS каждая секция подписана комментарием с номером экрана — стили ищутся по ним.

## Устройство

- Все 15 экранов лежат в DOM как `<section class="screen">`, активному добавляется `.active`,
  остальные скрыты. Движение только вперёд, по кнопке внизу.
- Сверху тонкий прогресс-бар: показывает, какой экран из 15 сейчас открыт.
- Экраны 10–12 переключают тему на «терминальную» (тёмный фон, моноширинный шрифт, зелёный текст),
  с экрана 13 возвращается тёплый стиль. Тема переключается атрибутом `data-theme` на `<body>`.
- Хранилища браузера не используются — только переменные в памяти, при перезагрузке всё с начала.
- Обратный отсчёт (экран 13) идёт до `CONFIG.GIFT_DATE` по локальному времени; если дата уже прошла,
  вместо таймера показывается «Время вышло. Иди забирай. 🐸».
